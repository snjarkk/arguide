# 測量ナビPro (arguide) システム仕様書

日本の平面直角座標（X, Y）を入力し、iPhoneなどのスマートフォンのカメラ映像上に目的地をAR（拡張現実）で表示するナビゲーションWebアプリです。

## 1. システム概要
公共測量の座標系（1系〜19系）に対応し、デバイスのGPS（位置情報）と電子コンパス（方位情報）を組み合わせて、目的地までの方向と距離をリアルタイムに案内します。

## 2. 主要機能
*   **平面直角座標の変換**: 入力された公共測量座標（X, Y, 系番号）を、ガウス・クリューゲル投影の逆計算アルゴリズムを用いて緯度・経度に変換。
*   **AR案内表示**: デバイスの背面カメラ映像を背景に、目的地の方角に赤いドットをオーバーレイ表示。
*   **リアルタイム距離計算**: 現在地から目標地点までの直線距離を算出し、「目標まで約◯◯.◯◯m」と小数点第2位まで表示。
*   **自動サイズ調整**: 目的地が近いほどARドットを大きく表示し、視覚的な直感性を向上。
*   **モバイルセンサー対応**: iOS/Android のカメラ、GPS、ジャイロセンサーの権限リクエストおよび連携。

## 4. 技術仕様
*   **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
*   **API**:
    *   **Geolocation API**: 現在地の緯度・経度取得。
    *   **DeviceOrientation API**: デバイスの向き（絶対方位）の取得。
    *   **MediaDevices API**: 背面カメラ映像の取得。
*   **計算ロジック**:
    *   **JGD2000/2011対応**: 日本の各座標系原点データを内蔵。
    *   **距離計算**: 大圏距離計算（Haversine式等）。
